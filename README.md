# Creora Cat

Landing page for Creora Cat, the mascot of the creora.ai ecosystem.

Static site: `index.html` + `assets/`. No build step.

## Deploy on GitHub Pages
1. Push these files to a repo.
2. Settings → Pages → Deploy from branch → `main` / root.

## Before launch, edit in `index.html`
- Ticker, network and contract address (Token section)
- X and Telegram links (Find the cat section)
